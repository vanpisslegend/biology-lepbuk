# Інтерактивний лепбук «Відділи скелета людини»

Це готовий статичний сайт українською мовою для шкільного проєкту з біології (8 клас).

## Як переглянути
1. Розпакуйте архів.
2. Відкрийте файл `index.html` у браузері (Chrome, Edge або Firefox).
3. Сайт працює без встановлення програм та без інтернету.

## Як опублікувати сайт і надіслати вчительці
Найпростіший спосіб — Vercel:
1. Увійдіть на https://vercel.com/ та створіть акаунт або увійдіть.
2. Створіть новий проєкт (Add New → Project).
3. Завантажте папку `biologia_lepbuk` у GitHub, а потім імпортуйте цей репозиторій у Vercel.
4. Для цього сайту не потрібні Build Command та Output Directory: це звичайний статичний сайт. Якщо Vercel попросить, залиште Framework Preset як Other, а Root Directory — папку з `index.html`.
5. Натисніть Deploy. Після публікації отримаєте посилання виду `назва-проєкту.vercel.app`, яке можна надіслати вчительці.

## Як змінити підпис автора
У `index.html` знайдіть текст `Біологія · 8 клас` або нижній підпис у футері й за бажанням додайте своє ім'я та клас.

## Важливо
Матеріал підготовлено як навчальний лепбук за темою «Відділи скелета людини». Формулювання та кількість окремих кісток можуть мати анатомічні варіації; для здачі роботи звірте терміни з підручником вашого класу.
